# 美股財報學院 v2.2

繁體中文互動財報入門教材，可切換 MRVL、AAPL、NVDA、AMD，觀察各公司自己的歷史財報。

- 入口：`index.html`，可直接使用瀏覽器開啟。
- GitHub Pages：https://mohyanmohyan-code.github.io/financial-statement-academy/
- 學習進度、公司選擇及作業內容儲存在使用者瀏覽器的 localStorage，不會傳送到伺服器。不同瀏覽器或網站來源的紀錄不會自動同步。
- 財報數據沿用原 v2.2 教材，資料日期為 2026-09-07；本次發布未重新審核所有財報數據，也不會自動更新。
- 本教材僅供教育用途，不構成投資建議。

## 本次公開版調整

移除原稿中的個人持股與金額，保留一般教學說明；移除原稿殘留的跨公司比較表及同業比較引導，統一為各公司與自己的過去比較。其餘教材與計算邏輯沿用原 v2.2。
